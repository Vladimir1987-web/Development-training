1. Контекст
IT-отдел крупного банка делает новую фичу для
личного кабинета клиента. Это виджет,
который показывает несколько последних
успешных банковских операций клиента.
Вам доверили реализовать этот проект,
который на бэкенде будет готовить данные для
отображения в новом виджете.
2. Продолжаем работу над виджетом банковских
операций клиента. В этом задании вам предстоит
использовать Git для сохранения истории развития
вашего проекта. Реализуйте новый функционал,
делая небольшие коммиты.
